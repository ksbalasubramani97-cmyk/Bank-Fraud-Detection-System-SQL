# 🏦 Bank Fraud Detection System using SQL

## 📌 Project Overview
This project detects suspicious banking transactions using SQL. It stores user, account, transaction, and fraud alert details in a MySQL database and generates fraud analysis reports.

## 🛠 Tools Used
- MySQL
- SQL
- MySQL Workbench

## ✨ Features
- User Management
- Account Management
- Transaction Tracking
- Fraud Detection
- Fraud Alerts
- Reports using SQL Queries

## 📊 SQL Concepts Used
- Joins
- Subqueries
- Views
- Aggregate Functions
- GROUP BY
- HAVING
- CASE Statement
